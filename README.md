# Dashboard de Performance Comercial - Nelogica

Dashboard interativo e centralizado para análise de performance do time comercial educacional da Nelogica.

## 📋 Sobre o Projeto

Este projeto visa substituir o processo manual de análise de planilhas por uma plataforma web segura, que permite análises rápidas, comparações históricas e geração de insights automáticos.

## 🎯 Funcionalidades Principais

- **Menu Geral**: Visão consolidada do desempenho do time
- **Detalhes por Funil**: Análise aprofundada por funil de vendas
- **CRM x Intranet**: Comparação de divergências entre sistemas
- **Resultados Gerais**: Rankings, gráficos e estatísticas
- **Comparações no Tempo**: Evolução temporal (4 semanas)
- **Insights**: Análises automáticas e recomendações

## 🎨 Identidade Visual

- Cores principais: Verde Nelogica (#8DC63F) e Azul Ciano (#00A9E0)
- Design moderno com bordas arredondadas
- Interface otimizada para apresentações executivas

## 🛠️ Tecnologias

- **Frontend**: React.js + Vite
- **Gráficos**: Chart.js / Recharts
- **UI**: Material-UI / TailwindCSS
- **Processamento**: SheetJS (xlsx)
- **Deploy**: Vercel / Netlify

## 📊 Atualização de Dados

Os dados são atualizados semanalmente através de upload de planilha Excel padronizada, contendo:
- 4 períodos de análise (semana atual + 3 anteriores)
- Métricas por vendedor e funil
- Dados de CRM e Intranet para comparação
